# نور — Noor (Website)

القرآن الكريم قراءة واستماعاً لأكثر من ٢٤٠ قارئاً، إذاعات القرآن مباشرة، الأذكار والتذكير، الحديث الشريف، مواقيت الصلاة مع الأذان، القبلة والختمة — مجاناً وبدون إعلانات.

**▶ Open the site:** https://mohamedashraf-sp.github.io/Noor-Quran-Web/

The Quran, azkar, hadith and prayer companion as a website — the same app as the
[Noor browser extension](https://github.com/MohamedAshraf-SP/Noor-Quran-Extention), running in any browser, including phones.

| Feature | |
|---|---|
| 📖 Mushaf | 114 surahs in Uthmani script, tafsir al-Muyassar, verse-by-verse audio |
| 🎧 Reciters | 240+ reciters in every riwayah, continuous playback, MP3 download |
| 📻 Radio & TV | Cairo, Sharjah, Makkah and 180+ live Quran radio stations, live Haramain TV |
| 🕌 Prayer | Offline prayer-time calculation, adhan alerts, Qibla |
| 🤍 Azkar | Morning/evening azkar, reminders, tasbeeh, 99 Names |
| 📗 Khatma | Daily reading plan with progress |
| 📜 Hadith | Bukhari, Muslim, Sunan, Nawawi's 40, Qudsi |

> Reminders and adhan alerts on the website work while the page is open. Install the extension to get them even when the browser tab is closed.

This site is generated from the extension's source with `tools/build-web.js` in the extension repo — edit there, then rebuild.

No ads, no tracking: everything is saved in your own browser.
